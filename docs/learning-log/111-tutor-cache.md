This PR makes the tutor's prompt cache work. The tutor has asked OpenRouter to cache its instructions since the start (`openrouter_cache_instructions=True`), but the setting did nothing: all the instructions came from one function that runs on every turn, and Pydantic AI 2.56.0 only puts the cache marker on instructions that are fixed text. The request on the wire was one plain system message with no `cache_control`, so every turn paid the full input price for the rules and the hint ladder.

Now the instructions are split in two. The rules that never change are one fixed string, `STATIC_INSTRUCTIONS`, given to the agent as `instructions=`: the role, the hint ladder L0 to L6 and how the ceiling works, the citation rules, the untrusted-text rules and the output format. The `[src:N]` rule is always in there now, worded "when retrieved documentation is present", so the text does not depend on whether a turn found docs. The few things that change every turn stay in the function: the lesson title and sections, the hint ceiling, the number of attempts, the misconceptions and the "learner is stuck" line. The request now has two system messages, the fixed one first with the cache marker on it and the per-turn one after it with none. Reads from the cache cost 0.1 times the normal input price, so every turn after the first within five minutes pays a tenth for the fixed part.

The fixed part is 2,878 characters, about 719 tokens by the rough rule of length divided by four. Anthropic caches nothing under 512 tokens on Haiku 5.5, so it is over the line without padding: every sentence in it is a real rule. A test fails if an edit ever pushes it under 512. Two small clean-ups came with the split: `TutorDeps.n_sources` is gone (it only chose between two citation texts), and the old `CITE_RULE` constants are folded into the fixed text.

Read `app/agents/tutor.py` first (the fixed text, then `_instructions`), then `tests/test_tutor_cache.py`. That test runs the real `OpenRouterModel` behind a mock HTTP transport, so no network and no key are involved, and it checks the exact request body: the marker is on the fixed part only, it is the only marker in the body, and the fixed bytes are identical from one turn or lesson to the next. The mock transport comes from `httpx2`, the client library Pydantic AI 2.56 uses itself. The older `httpx` still works but prints a deprecation warning. `tests/test_tutor_rag.py` was updated to match the new layout and gained one test: finding docs or not changes the learner's turn and never the instructions. `docs/SPEC.md` section 7 has a short note: static instructions are cached, dynamic parts are not.

Lesson learned: a setting can be accepted and still do nothing, and the only way to know is to look at what really goes over the wire. The lesson PA6 found the problem by capturing the request; this PR fixes it and keeps a test that captures the request again. The rule of thumb: put what never changes first and as fixed text, and keep what changes every turn out of it, because a single changed character in the cached part makes the whole cache miss.
