This adds the Pydantic AI lesson "Instructions and model settings" (`pa6-instructions-and-settings`). Every request to a model carries words (instructions) and numbers (settings), and the lesson teaches both. It shows what the model request really carries for `instructions` and for `system_prompt`, and what each one does when you continue a chat with `message_history`: instructions are rebuilt by the agent you run now, while a system prompt lives in the history and is not added to a non-empty one. It covers static instructions, dynamic `@agent.instructions` functions (sync or async, with `RunContext`, run again on every run) and per-run `instructions=`. The docs class per-run instructions as dynamic, but in 2.56.0 they are flagged static and a cache marker lands on them, so they are a poor place for text that changes on every call. Then it covers `ModelSettings` (`max_tokens`, `timeout`, and the shared `thinking` and `cache` keys), the order in which the model, the agent and the run settings merge (key by key, run wins), provider settings such as `OpenRouterModelSettings`, and the rule this site follows: never set `temperature` on Claude 5.x models. It describes how `app/agents/tutor.py` and `app/agents/grader.py` are set up, and points to a later lesson (PA11) for `UsageLimits`. The lesson has six sections, a two-question warm-up, a six-item quiz (four single-choice, one ordering, one fill-in), two think-deeper questions and a hands-on task. In the task you build a persona agent in `persona.py`: a `PersonaDeps` dataclass, a dynamic instructions function that reads it, and a `settings_for(tone)` helper whose token cap is set for one run only.
