One lesson learned: the command the brief suggests, `gh api repos/anthropics/claude-code-action/git/ref/tags/<tag>`, does not return a commit for this repo. The release tags are annotated, so it returns the SHA of the tag object (`"type": "tag"`), one step before the commit. You have to follow it with `git/tags/<sha>`, or ask `commits/<tag>` instead. The workflow checker cannot tell the two apart, because both are 40 hex characters. Always read the `type`.
