Then it teaches agent delegation (a tool of one agent runs a second agent), why that tool must be `async def` (`run_sync` inside a tool raises `UserError`), passing `usage=ctx.usage` so one counter and one `UsageLimits` cover both agents, passing `deps=ctx.deps` so both agents share the same object, and what a delegate does and does not see. One lesson learned: usage is not shared by itself. With the `usage=ctx.usage` line removed, the same run gave `requests=2` instead of `4`, and a `request_limit=3` that should have stopped it never fired.
