It then shows why git cannot settle a conflict by itself, how to resolve one on the command line (fetch, merge `origin/main` into your branch, edit the markers, add, commit, push), how to keep branches short-lived so conflicts stay rare, and how to undo a merged pull request with the Revert button or `git revert`. It ends with `gh pr merge --squash --delete-branch` and auto-merge.
