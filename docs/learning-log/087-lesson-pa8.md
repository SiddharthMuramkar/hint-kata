One lesson learned: `TestEmbeddingModel` in 2.56.0 gives every text the same vector, eight numbers that are all `1.0`. That is perfect for checking the plumbing, but every cosine score ties, so it cannot test a ranking. The hidden tests use a small subclass that keeps the `TestEmbeddingModel` result and replaces the vectors with word counts, so the right order is known before the test runs. Two smaller surprises: the `Embedder` hands a long list to the model in one call and does not split it, so batching is up to you (this site uses 64), and with only `pydantic-ai-slim[openrouter]` installed the OpenAI-style embedding model would not import until `tiktoken` was installed, which PR #105 adds.
