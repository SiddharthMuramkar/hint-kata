One lesson learned: a scripted model is so fast that `stream_text()` groups all its chunks into one item, even with `delta=True`. The default `debounce_by=0.1` groups chunks that arrive within 0.1 seconds. Pass `debounce_by=None` to get one item per chunk, which is what a test needs.
