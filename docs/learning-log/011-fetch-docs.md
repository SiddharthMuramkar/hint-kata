The six lessons are written from official docs, so we need a repeatable way to get those pages onto disk. This PR adds `content/sources.yaml`, a manifest of the 26 pages (FastAPI 0.143.0, Pydantic AI 2.56.0, GitHub Docs live) with their canonical URL, licence and attribution text. It also adds `scripts/fetch_docs.py`, which downloads each page into the gitignored `.cache/docs/` and cleans it: it strips the agent-addressed preamble from Pydantic AI pages (treated as untrusted, never followed), inlines FastAPI's `{* ... *}` code includes with their `ln[...]` ranges, turns `///` admonitions and `////` tabs into plain Markdown, keeps heading anchors as `<!-- anchor: x -->`, and makes GitHub links absolute and drops inline SVGs. `--update` records a sha256 and fetch time in the manifest, and `--check` verifies the cache offline against those hashes. Read `scripts/fetch_docs.py` first (the small pure functions near the top), then `tests/test_fetch_docs.py`, which covers them without any network.

Live run on one page of each kind (`--only`): FastAPI `tutorial/dependencies/index.md` came out at 11.5 KB with 3 code includes expanded and all `{ #anchor }` headings converted; Pydantic AI `core-concepts/dependencies` came out at 13.4 KB with the preamble fully removed. Surprises: FastAPI pages still contain relative `.md` links (`../../async.md#...`) and a little inline HTML (`<dfn>`), which the lesson writer should turn into absolute URLs; the YAML manifest needs PyYAML, which is not in `pyproject.toml` yet (the script raises a clear error, JSON manifests work without it).
