This PR adds the first Pydantic AI lesson, "Your first agent" (`content/pydantic-ai/pa1-first-agent/`). It teaches what an `Agent` holds (model, instructions, output type, tools), the `provider:model` string and why `Agent("gpt-5")` raises a `UserError` in V2, why `instructions=` beats `system_prompt=`, running with `run_sync` and `await run` (`result.output`, `result.usage` as a property), and structured output with a Pydantic model. The lesson has six reading sections, 2 warm-up questions, 5 quiz items (3 single choice with a named misconception on every wrong option, 1 ordering, 1 fill-in-the-blank) and 2 think-deeper questions with 4 binary rubric criteria each. The hands-on task asks the learner to build a `CityFacts` model and a `make_agent()` function; its hidden tests use `TestModel`, so no API key is needed. It also adds one generic test, `tests/test_lesson_tasks.py`, that runs every `content/*/*/task` against its `solution/` (must pass) and its `starter/` (must fail), the same way the checker does, so later lessons get this safety net for free. Every API in the lesson was checked against the installed Pydantic AI 2.56.0. Read `content/pydantic-ai/pa1-first-agent/lesson.md` first, then `task/tests/test_first_agent.py`.
