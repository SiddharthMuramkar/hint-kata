One lesson learned: `TestClient` (and `httpx.ASGITransport`) run the whole app before they return, so a test can check what a stream sent but never when. With a fake model that waited 0.4 seconds between chunks, `client.stream(...)` opened after about 1.6 seconds and all the lines were there at once; only a live server read with `httpx.stream` showed the events arriving at 0.46, 0.86, 1.27 and 1.67 seconds. Smaller surprises: a generator route without `response_class=EventSourceResponse` does not fail, it quietly streams JSON Lines (`application/jsonl`); an exception inside the generator gives a `200` whose body is cut off, and the `tutor.js` loop just sees the stream end as if the reply were finished (5 runs out of 5 in Node 24), so the route needs its own `try`/`except` and an `error` event; and a client that leaves early cancels the generator, so a save placed after the last `yield` (as the tutor route has) is skipped.
