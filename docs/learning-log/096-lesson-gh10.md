The lesson has six sections plus an intro. They cover memory files (`CLAUDE.md`, `.claude/rules/*.md` with and without `paths:`, `.claude/agents/*.md`), worktrees for parallel agents, and guard-rails (the allow and deny lists in `.claude/settings.json`, the eight hookify rules, the two hook scripts and the GitHub ruleset). The hands-on task has the learner ask Claude Code (or do it by hand) for a `claude/first-change` branch, one commit and a pull request whose body says "Claude Code". Then they review the diff with the lesson's checklist and leave it unmerged.
