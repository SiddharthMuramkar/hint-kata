# Lesson content

- Write in your own words from the cached source pages. Never copy doc text. No Claude Code doc text at all: link only, with a short original summary.
- Every lesson ends with an attribution footer: source title, URL, version or date, licence.
- Every source has an entry in `content/sources.yaml` with its licence (MIT for FastAPI and Pydantic AI, CC BY 4.0 for GitHub Docs and MCP docs).
- No GitHub logos or marks. Say the site is not affiliated with GitHub, FastAPI or Pydantic.
- Each lesson passes the content validators, and its task checker passes on the solution and fails on the starter.
